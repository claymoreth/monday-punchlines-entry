## Entry

`main.py` (Python 3.13, standard library only, no network) writes one joke
about Monday mornings to `entry.txt` in the output directory
(`MAKEFUN_OUTPUT_DIR`, default `/output`):

> My weekend was a free trial. Monday is the subscription renewal email.

70 characters, one line, no trailing newline.

## Run

```sh
python3 main.py
```
